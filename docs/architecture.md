# Architecture and supported versions

Chaos UI shares rendering and interaction in Lit shadow-DOM components. React uses `@lit/react` for property/event mapping. Angular uses standalone adapters and typed inputs/outputs. The adapters must not duplicate game logic.

```text
packages/chaos-ui (Lit) → packages/react → playground + React example
                       → packages/angular (APF) → Angular example
```

## Component boundary

Loto OTP and Infinity OTP are implemented. Core exports `ChaosLotoOtpElement` and `ChaosInfinityOtpElement` at their own entrypoints, with explicit idempotent `/loto-otp/register` and `/infinity-otp/register`. Shared OTP types/normalizers and edit operations are in the core; artwork/rendering stay component-specific. React exports `ChaosLotoOtp` and `InfinityOtp` (`ChaosInfinityOtp` alias). Angular exports the standalone `ChaosLotoOtpComponent` and `ChaosInfinityOtpComponent` with model binding and CVA. Volume Gym still exposes a preliminary type contract only. See [Loto API](loto-otp.md) and [Infinity API](infinity-otp.md).

`packages/*/testing` retains the private foundation probe. It is excluded from package exports/tarballs. Both examples exercise public Loto and Infinity imports as well as the private probe. The pack smoke test installs actual tarballs outside the workspace, typechecks and builds both examples against them; only the private probe harness is copied from source. Production rendering is consumed from the packed public packages.

## Runtime and packaging

Core uses TypeScript ESM output, explicit extensions and declarations. Angular secondary entrypoints are generated by ng-packagr as FESM2022 with partial compilation configured. No framework dependency enters core. All registration happens in a function call, guarded for missing `customElements`; a repeated call with the same constructor is a no-op, and a conflicting definition throws.

No public import injects CSS or registers elements; library manifests therefore declare `sideEffects: false`. Fixture styles are Lit static CSS inside shadow DOM, so each instance owns its rendering. The app stylesheet is bundled by Vite/Angular and is not a library asset. All artwork is local CSS/text; no external fonts or image paths are required.

Supported behavior: browser client interaction. Importing public package entries in Node is tested independently. Full SSR rendering, declarative shadow DOM hydration, cross-version framework support, and full accessibility certification remain unverified. Browser evidence is Chromium desktop and mobile emulation, not physical-device or Safari/Firefox certification.

Angular raw Node imports preload the JIT compiler because APF libraries use partial declarations; actual apps use Angular linking. This framework requirement is separate from DOM safety. The public Loto output is also checked for partial declarations.
