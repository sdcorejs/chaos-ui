# Chaos UI by sdcorejs

Simple tasks. Ridiculous interfaces.

Loto OTP and Infinity OTP are available through their component entrypoints. Core has explicit `/loto-otp/register` and `/infinity-otp/register` entrypoints and shared `/otp` contracts. React supports controlled/uncontrolled input; Angular supports standalone model binding and Reactive Forms (choose one per instance).

See https://github.com/sdcorejs/chaos-ui/blob/main/docs/loto-otp.md and https://github.com/sdcorejs/chaos-ui/blob/main/docs/infinity-otp.md for properties, typed events, examples, normalization, CSS variables/parts and lifecycle rules. Exact supported versions are in docs/architecture.md. Client interaction only; full SSR/hydration is not claimed. Volume Gym is not implemented. No npm release has been made.
